You are a senior full-stack developer, SaaS architect, and conversion-focused product designer.

Your task is to design and implement:
1. A complete subscription payment system
2. A freemium usage model
3. A high-converting pricing page

This platform is a SaaS tool that analyzes advertising reports and provides insights.

---

# 🎯 OBJECTIVES

- Implement recurring subscription billing
- Support both international and South African payments
- Enforce a freemium usage model
- Design a pricing page that converts users into paying customers

---

# 💳 PAYMENT SYSTEM ARCHITECTURE

## Payment Providers:
1. Stripe → International users + subscriptions
2. PayFast → South African users

---

## 🌍 USER LOCATION LOGIC

- Detect user location via IP or user selection
- If South Africa:
  - Show PayFast as primary option
  - Allow Stripe as secondary option
- If International:
  - Use Stripe only

---

# 💰 PRICING STRUCTURE

## 🟢 Free Plan
- No login required for first report
- After 1 report → force account creation
- Logged-in free users:
  - 3–5 reports per month
- Limited insights
- No historical data

---

## 🔵 Basic Plan (Solo Users)
- Price:
  - R279/month OR $15/month
- Features:
  - 1 user
  - Unlimited reports
  - Core insights
  - Limited history (30 days)

---

## 🟣 Pro Plan (Agencies)
- Price:
  - R999/month OR $49/month
- Features:
  - Multi-user access (3–10 users)
  - Unlimited reports
  - Advanced insights + recommendations
  - Report export (PDF)
  - Full history
  - Priority support

---

## 💡 FUTURE (optional but recommended)
- Annual pricing (2 months free)
- Example:
  - R279/month OR R2,790/year

---

# 🆓 FREEMIUM USAGE LOGIC

1. Non-logged-in users:
   - Allow 1 free report
   - Then require signup

2. Logged-in free users:
   - Track report usage in database
   - Limit to X reports/month

3. When limit reached:
   - Block report generation
   - Show upgrade paywall
